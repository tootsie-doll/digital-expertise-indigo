# Цифровая экспертиза · Аналитика

Самостоятельный React-проект для локального запуска в WebStorm.
React + TypeScript + Vite. Графики текущего прототипа построены на Recharts.

## Данные

Все числа и рейтинги — демонстрационные. Количество организаций, изменение активности и рейтинг не являются подтверждёнными результатами запросов к БД. Показатель динамики +18,4% — фиксированный пример.
«Количество заявителей» означает всех зарегистрированных пользователей сервиса ЛП и не зависит от периода.
В текущей версии нет подключения к БД, API, авторизации и телеметрии.
Для рабочих данных необходим внутренний backend, выполняющий согласованные агрегирующие SQL-запросы к contracts под пользователем с правами SELECT. Пароли и подключение PostgreSQL нельзя добавлять в React-код.
Установка npm-пакетов требует доступа к реестру npm; после установки графики и стили не используют внешние сервисы.

## Шрифт Roboto

Первый визуальный вариант. Roboto включён локально в public/fonts: кириллица и латиница, начертания 400, 500, 600, 700. Внешних запросов к сервисам шрифтов нет. Лицензия находится рядом с файлами шрифта.

## Альтернативное оформление — Indigo

Объёмные синие панели, фиолетовые акценты, общая округлая рамка. Главный график: столбцы ЛП и линия МИ. Roboto включён локально. Данные демонстрационные.
